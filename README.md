# acigami.github.io

Mi sitio personal: portfolio, enlaces y un sandbox de experimentos que corren en el navegador. Vive en [acigami.github.io](https://acigami.github.io).

Hecho con [Astro](https://astro.build), con islas de Preact para las partes interactivas. Cada push a `main` se publica solo con GitHub Actions.

## Desarrollo

```
npm install
npm run dev      # http://localhost:4321
npm run build    # genera dist/
```
