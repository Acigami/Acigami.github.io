Este sitio es mi carta de presentación y mi banco de pruebas. Está hecho con [Astro](https://astro.build): páginas estáticas en HTML y Markdown, con islas de JavaScript solo donde hay algo interactivo. El código vive en un repo de git y, una vez conectado a GitHub, se publica solo con cada push.

La idea de fondo está en el plan del proyecto: un lugar para el portfolio, un hub para centralizar lo que hago y un sandbox para probar ideas sin miedo a romper nada.
